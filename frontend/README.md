# Yamil Chacon - Derecho y Sociedad

Frontend del sitio web de Derecho y Sociedad, construido con Next.js.

## Scripts

```bash
npm run dev
npm run build
npm run lint
```

## Variables de entorno

```env
NEXT_PUBLIC_API_URL=https://yamilapp-backend.onrender.com
```

## Produccion

El frontend se despliega en Vercel y utiliza el backend publicado en Render.
